# PAIR CARRY — 二つずつ運んで白黒に分ける

黒と白が交互に並んだ碁石を、となり合う 2 個ずつ空いた所へ動かして、黒と白に分けるパズル。組が増えるほど、どこから崩すかが難しくなる。1 列と市松の盤。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/pair-carry/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 黒と白が交互に並んでいる。黒と白に分けて、すき間なく並べたらクリア（黒が左でも右でもよい）。
2. 石をタップすると、となりの石と 2 個組で持ち上がる（相方は、石の中のタップした側のとなり）。空いている所をタップすると、タップした石がそこへ、相方がそのとなりへ、並びはそのままで動く。置ける所は光る。
3. 手数が少ないほどよい。いちばん少ない手数も出る。

- 持っている石をもう一度タップすると置かずにやめる。ほかの石をタップすると持ち替える。
- 市松の盤だけ「回す」で組の向きを 90° ずつ変えられる（手数に数えない）。市松は石が正方形にすき間なく入り、上下か左右の半分で色が分かれたらクリア。
- ステージは 10（1 列 8・市松 2）。どれも最初から選べる。「1 手もどす」「はじめから」がある。
- ステージごとに、クリアしたときのいちばん少ない手数を記録する。音はタイトルの「音 オン / オフ」で切り替えられる。
- 1 列のパズルは、1884 年に P. G. テイトが紹介した古いパズル。n 組なら n 手で分けられる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node test.mjs                 # 動かす・クリア判定・最少手数・保存のテスト（フレームワークなし）
```

| ファイル | 中身 |
|---|---|
| `logic.js` | 盤・動かす・クリア判定・ステージの表・保存する値の確かめ（DOM に触らない） |
| `main.js` | 画面の切り替え・操作・描画・音 |
| `test.mjs` | `logic.js` のテスト。ステージの最少手数を探索で確かめる |

- 盤は 1 列も市松も R 行 × C 列のマス（1 列は R = 1）。`cells[r * C + c]` = 0（空き）/ 1（黒）/ 2（白）。
- 持ち上げた 2 マスは置くまで「石がある」扱い（1 マスだけずらす手はない）。
- 最少手数: ステージ 1〜9 は、はじめの盤から幅優先探索で 1 手ずつ広げ、はじめてクリアの形が出た手数（その手数より少ない並びはすべて調べている）。
  ステージ 10（市松 4×4、8×8 マス）は状態が多すぎて幅優先では調べきれないので、手数の少ない順に深めていく探索（IDA\*）で 6 手以下の解がないことを確かめ、7 手の解を 1 つ持っている（最少 7）。
  枝の切り方: 1 手で動くのは 2 個なので、クリアの形（4×4 の置き場所 25 通り × 分け方 2 × 色 2）ごとに「正しい所にない石の数 ÷ 2（切り上げ）」より早くは終わらない。となり合う 2 手が別々のマスしか触らないときは順番を 1 通りだけ調べる。
- **公開したあとでステージの中身（盤の大きさ・石の数と位置）を変えない**（記録と最少が合わなくなる）。変えるなら保存の版を上げる。
- 保存は端末内の `localStorage`。`pair-carry.settings`（`{ v: 1, sound }`）と `pair-carry.progress`（`{ v: 1, best: { '1': 3 } }`。キーはステージ番号、値はクリアしたときの手数の最少）。
